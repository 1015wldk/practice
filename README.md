# 할 일 관리 앱

HTML/CSS/JavaScript만으로 만든 간단한 할 일 관리 앱입니다. 빌드 도구나 설치가 필요 없습니다.

## 실행 방법

`index.html` 파일을 브라우저로 열면 바로 실행됩니다.

로컬 서버로 띄우고 싶다면:

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 http://localhost:8000 을 엽니다.

## 기능

- 할 일 추가 (입력 후 Enter 또는 "추가" 버튼)
- 완료 표시 / 해제 (체크박스)
- 수정 (항목 더블클릭 → Enter로 저장, Esc로 취소, 내용을 비우면 삭제)
- 삭제 (✕ 버튼)
- 필터: 전체 / 진행 중 / 완료
- 모두 완료 / 모두 미완료 전환, 완료 항목 일괄 삭제
- 브라우저 `localStorage`에 자동 저장 (새로고침해도 유지)
- 시스템 설정에 따른 다크 모드

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 스타일 (라이트/다크 테마) |
| `app.js` | 앱 동작과 저장 로직 |
