# 실습일지 도우미

「실습일지 작성 요령 안내문 (성인학습자용)」을 바탕으로 만든 사회복지 현장실습 일지 작성 도우미입니다.

일지를 **대신 써 주지 않습니다.** 안내문은 “생성형 AI로 대신 쓴 일지는 슈퍼비전의 의미가 사라진다”고 말합니다. 그래서 이 앱은 정해진 틀을 제공하고, 직접 쓴 글이 작성 원칙에 맞는지 규칙으로 점검하는 일만 합니다.

## 실행 방법

설치할 것이 없습니다. `index.html` 파일을 브라우저로 열면 바로 실행됩니다.

로컬 서버로 띄우려면:

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 http://localhost:8000 을 엽니다.

## 기능

| 안내문의 내용 | 앱의 기능 |
| --- | --- |
| 당일 키워드 메모, 15분 작성 | 키워드 메모 칸(일지 본문에는 포함 안 됨), 15분 작성 타이머 |
| 일지의 구성 4항목 | 실습 내용 / 관찰·분석 / 소감·성찰 / 질문·향후 계획 칸. 각 칸에 “써야 할 내용”과 “흔한 실수” 표시 |
| 성찰 3단계 | 소감·성찰을 무엇을(What?) → 그래서(So what?) → 앞으로(Now what?)로 나눠 작성 |
| 이론·가치와 연결 | 강점관점, 생태체계, 자기결정권 등 개념 설명 칩 |
| 제출 전 자가 점검 7항목 | 글을 쓰는 동안 자동 점검하고, 직접 확인한 항목은 체크 |
| 매일 비슷한 문장 복사 금지 | 다른 날 일지와 똑같은 문장이 반복되면 경고 |
| 작성 요령 | “작성 요령” 탭에 원칙 6가지와 고쳐 쓰기 예시 |
| 앱 사용법 | “사용 설명서” 탭에 시작하기, 일지 쓰기, 자가 점검, 제출, 백업, 질문 챗봇, 자주 묻는 질문 |
| 막힐 때 질문 | “질문하기” 탭의 Claude 챗봇. 작성 원칙에 맞게 답하고 일지는 대신 쓰지 않음 |

그 밖에:

- 일지 목록(날짜순)과 항목별 점검 점수
- 텍스트 복사, `.txt` 파일 저장, 인쇄용 레이아웃
- 백업 파일(.json) 내려받기와 불러오기
- 휴대폰 화면 지원, 시스템 설정에 따른 다크 모드

## 질문 챗봇

“질문하기” 탭에서 학생이 실습일지에 관해 묻고 Claude가 답합니다. 서버가 없는 정적 사이트라서 **브라우저가 Anthropic API를 직접 호출**합니다.

- **API 키**: “설정” 탭에서 입력합니다. 키는 그 기기의 브라우저(localStorage 또는 탭을 닫으면 지워지는 sessionStorage)에만 저장되고, 일지 데이터와 백업 파일에는 들어가지 않습니다. 코드와 저장소에는 키가 없습니다.
- **모델**: “최신 모델 불러오기”가 `GET /v1/models`로 그 키로 쓸 수 있는 Claude 모델을 가져와 최신순으로 보여 줍니다. 목록을 불러오기 전에는 기본 목록(`js/chat.js`의 `FALLBACK_MODELS`)을 씁니다.
- **역할**: `js/chat.js`의 `SYSTEM_PROMPT`에 안내문의 원칙을 담았고, 일지 대필 금지·개인정보 입력 금지를 지시합니다. 프롬프트 지시라서 완벽하지는 않습니다.
- **개인정보**: 챗봇에 입력한 질문만 api.anthropic.com으로 전송됩니다. 쓰고 있는 일지는 전송하지 않습니다. 전화번호·실명처럼 보이는 표현이 있으면 보내기 전에 경고합니다. 대화 내용은 저장하지 않고 화면을 닫으면 사라집니다.
- **주의**: 이 방식은 키를 쓰는 사람이 자기 기기에서 직접 입력해야 합니다. 한 개의 키를 여러 학생에게 공유하면 학생이 브라우저에서 키를 볼 수 있습니다. 학생 전체가 키 없이 쓰게 하려면 서버(예: Vercel 함수)를 두고 키를 환경 변수로 보관해야 합니다.

## 자동 점검 항목

| 점검 | 방법 |
| --- | --- |
| 비밀보장 | 전화번호, 주민등록번호, 이메일, 주소 형태, “김영희씨”처럼 성+이름+호칭 형태를 찾음 |
| 육하원칙 | 실습 내용에서 언제·어디서·누구와·무엇을에 해당하는 표현을 찾고, 시간표 나열(시각으로 시작하는 줄 3개 이상)을 알림 |
| 사실과 해석 구분 | 실습 내용의 감정·해석 표현(“화를 냈다”, “좋아하셨다”)과 관찰·분석의 주관적 평가(“고집이 셌다”)를 찾음 |
| 이론·가치 연결 | 강점관점, 생태체계, 자기결정, 윤리강령, 상호작용 등 관련 어휘가 있는지 확인 |
| 판단·낙인 표현 | “불쌍한”, “문제 가정”, “말을 안 듣는” 등을 찾아 바꿔 쓸 방향을 제안 |
| 성찰 3단계 | 세 단계가 채워졌는지, “보람찼다”, “뜻깊었다”로 끝나지 않았는지 확인 |
| 질문·향후 계획 | 비어 있지 않은지, 슈퍼바이저께 드릴 질문이 있는지 확인 |

자동 점검은 단어 규칙에 따른 **참고용**입니다. 놓치는 표현도 있고, 문제없는 표현을 잘못 짚을 수도 있으니 최종 확인은 직접 해 주세요.

## 개인정보

작성한 일지는 **이 브라우저(localStorage)에만** 저장되고 어디로도 전송되지 않습니다(질문 챗봇에 직접 입력한 질문만 예외로 Anthropic 서버로 전송됩니다). 브라우저 데이터를 지우거나 기기를 바꾸면 사라지므로, 목록 화면의 “백업 / 불러오기”로 가끔 백업해 두세요. 공용 컴퓨터에서는 사용 후 일지를 삭제하세요.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 (목록, 작성, 작성 요령, 사용 설명서, 질문하기, 설정) |
| `style.css` | 스타일 (라이트/다크, 모바일, 인쇄) |
| `js/checks.js` | 자동 점검 규칙 |
| `js/app.js` | 저장, 화면 전환, 타이머, 내보내기 |
| `js/chat.js` | 챗봇 로직(시스템 프롬프트, 모델 목록 정리, 스트리밍 해석, 오류 문구) |
| `js/chat-ui.js` | 질문하기·설정 화면 |
| `tests/checks.test.js` | 점검 규칙 테스트 |
| `tests/chat.test.js` | 챗봇 로직 테스트 |

## 테스트

```bash
node --test tests/checks.test.js tests/chat.test.js
```
