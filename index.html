      실습일지 작성 요령

      실습일지는 “무엇을 했는가”보다 “어떻게 생각했는가”를 쓰는 글입니다.

      먼저 알아둘 점

      • 경험은 강점이자 함정 — “내가 해보니 이게 맞다”로 끝내지 말고, 이론·가치·윤리의 관점으로 다시 해석합니다.
      • 시간 부족 — 당일 키워드 메모와 15분 작성을 권합니다.
      • 글쓰기 부담 — 잘 쓰려 하지 말고 정해진 틀에 맞춰 씁니다. 하루 일을 다 쓰지 않아도 됩니다.
      • 일지의 쓸모 — 슈퍼비전 자료이자, 앞으로 실무 기록을 쓰는 능력의 기초가 됩니다.

      작성 원칙 6가지

      1. 사실과 해석을 구분한다. “A씨가 화를 냈다”(해석) 대신 “A씨가 목소리를 높이며 서류를 책상에 내려놓았다”(사실)를 먼저 쓰고, 그다음에 해석을 씁니다.
      2. 구체적으로 쓴다. 육하원칙 기준. “프로그램 보조를 했다”보다 “어르신 12명 대상 인지향상 프로그램에서 도구 배부와 개별 보조를 맡았다”.
      3. 비밀보장을 지킨다. 실명, 주소, 연락처, 특정 가능한 정보는 쓰지 않습니다. 이니셜이나 가명(A씨, 70대 여성).
      4. 이론·가치와 연결한다. 강점관점, 생태체계, 자기결정권, 사회복지사 윤리강령 등과 한두 줄이라도.
      5. 판단·낙인 표현을 피한다. “불쌍한”, “문제 가정”, “말을 안 듣는” 같은 표현을 점검합니다.
      6. 자기 성찰을 담는다. 내가 느낀 감정이 내 경험·가치관과 어떻게 이어지는지 돌아봅니다.

      성찰 쓰기 틀: 무엇을 → 그래서 → 앞으로

      고치기 전

      오늘은 경로당 어르신들과 프로그램을 했다. 어르신들이 너무 좋아하셔서 보람 있었다. 예전에 요양원에서 일할 때도 비슷했는데 역시 어르신들은 관심을 받는 걸 좋아하시는 것 같다.

      고친 후

      오전 10시, ○○경로당 어르신 9명 대상 회상 프로그램에서 진행 보조를 맡았다. 처음에 참여를 거부하던 B씨(80대 여성)가 다른 어르신이 젊은 시절 사진을 소개하자 자신도 결혼사진 이야기를 시작했다. 나는 예전 요양원 근무 경험상 ‘관심을 주면 참여하신다’고 생각했는데, 오늘은 내가 개입하기보다 동료 어르신의 이야기가 계기가 되었다. 이는 집단 내 상호작용의 힘을 보여주는 장면이라고 생각한다. 다음 회기에는 참여가 적은 어르신이 다른 분의 이야기에 반응할 수 있도록 순서를 조정해 보고 싶다. 이에 대해 슈퍼바이저님의 의견을 여쭙고 싶다.

      고친 후 글에는 사실, 기존 경험과의 비교, 새로운 해석, 다음 계획, 질문이 모두 들어 있습니다.

      앱 사용법이 궁금하면 사용 설명서를 보세요.

      시간 관리 팁

      • 실습이 끝나면 휴대폰 메모에 키워드만 남기고, 그날 안에 15분 안팎으로 작성합니다.
      • 몰아서 쓰면 성찰이 빠지고 나열만 남습니다.
      • 매일 비슷한 문장을 복사해 붙이거나 생성형 AI로 대신 쓴 일지는 슈퍼비전의 의미가 사라집니다. 학교와 기관의 기준을 따릅니다.

      사용 설명서

      이 앱은 일지를 대신 써 주지 않습니다. 정해진 틀을 보여 주고, 직접 쓴 글이 작성 원칙에 맞는지 점검만 도와줍니다.

      처음 시작하기 일지 쓰기 자가 점검 제출하기 저장과 백업 질문하기(챗봇) 자주 묻는 질문

      1. 처음 시작하기

      1. 인터넷 주소를 휴대폰이나 컴퓨터 브라우저로 엽니다. 설치나 회원가입은 필요 없습니다.
      2. 휴대폰에서는 브라우저 메뉴의 ‘홈 화면에 추가’를 누르면 앱처럼 바로 열 수 있습니다.
      3. 첫 화면(일지 목록)에서 ‘오늘 일지 쓰기’를 누르면 오늘 날짜로 새 일지가 열립니다. 지난 날짜의 일지는 ‘다른 날짜로 새 일지’로 만듭니다.

      2. 일지 쓰기

      작성 화면은 위에서 아래로 차례대로 채우면 됩니다. 입력하는 즉시 자동 저장되므로 따로 저장 버튼을 누를 필요가 없습니다.

      화면 요소사용법
      15분 작성 타이머시작을 누르고 15분 안에 핵심 장면 1~2개만 씁니다. 시간이 지나도 계속 쓸 수 있습니다.
      실습 날짜·기관날짜와 기관 이름을 적습니다. 기관명은 ‘○○복지관’처럼 써도 됩니다.
      📝 키워드 메모실습 직후 떠오르는 단어만 적어 두는 칸입니다. 일지 본문에는 들어가지 않습니다.
      1. 실습 내용언제, 어디서, 누구와, 무엇을 했는지 사실만 씁니다.
      2. 관찰·분석관찰한 행동을 있는 그대로 쓰고, 이론과 연결해 봅니다.
      3. 소감·성찰무엇을 → 그래서 → 앞으로 세 칸을 차례로 채웁니다. 아래 ‘연결해 볼 만한 이론·가치’를 펼치면 강점관점, 자기결정권 같은 개념의 짧은 설명을 볼 수 있습니다.
      4. 질문·향후 계획슈퍼바이저께 여쭐 질문과 다음에 해 볼 일을 씁니다.

      각 칸 위의 써야 할 내용과 흔한 실수 안내를 먼저 읽고 쓰면 고칠 일이 줄어듭니다. 작성 원칙은 작성 요령 탭에 자세히 있습니다.

      3. 제출 전 자가 점검

      컴퓨터에서는 작성 화면 오른쪽, 휴대폰에서는 화면 아래 ‘점검 보기’ 버튼을 누르면 점검 목록이 나옵니다. 글을 쓰는 동안 다음 항목을 자동으로 살펴봅니다.

      • 비밀보장: 실명(“김영희씨”), 전화번호, 주소 같은 정보가 있는지
      • 육하원칙: 실습 내용에 언제·어디서·누구와·무엇을이 들어 있는지, 시간표만 나열하지 않았는지
      • 사실과 해석 구분: “화를 냈다”, “고집이 셌다” 같은 해석·평가 표현이 있는지
      • 이론·가치 연결: 관련 개념을 한 번이라도 언급했는지
      • 판단·낙인 표현: “불쌍한”, “문제 가정” 같은 표현과 바꿔 쓸 방향
      • 성찰 3단계: 세 칸을 모두 채웠는지, “보람찼다”로 끝나지 않았는지
      • 질문·향후 계획: 비어 있지 않은지

      경고가 뜨면 해당 문장을 고쳐 보고, 직접 읽어 확인한 항목은 체크해 두세요. 다른 날 일지와 똑같은 문장을 반복하면 따로 알려 줍니다.

      자동 점검은 단어 규칙에 따른 참고용입니다. 놓치는 표현도 있고, 문제없는 표현을 짚을 수도 있습니다. 최종 확인은 직접 해 주세요.

      4. 제출하기

      작성 화면 아래 버튼으로 일지를 꺼낼 수 있습니다. 학교·기관이 정한 제출 양식에 맞춰 골라 쓰세요.

      • 일지 텍스트 복사: 4개 항목이 정리된 글을 복사합니다. 한글(HWP)·워드 양식이나 학교 시스템에 붙여 넣습니다.
      • 텍스트 파일로 저장: .txt 파일로 내려받습니다.
      • 인쇄: 인쇄용 화면으로 출력하거나, 인쇄 창에서 ‘PDF로 저장’을 고르면 PDF가 됩니다.
      • 이 일지 삭제: 일지를 지웁니다. 되돌릴 수 없으니 주의하세요.

      5. 저장과 백업

      • 일지는 지금 사용하는 기기의 브라우저 안에만 저장됩니다. 서버로 전송되지 않고, 다른 사람이 볼 수 없습니다.
      • 그래서 휴대폰에서 쓴 일지는 컴퓨터에서 보이지 않습니다. 기기를 옮길 때는 일지 목록 → 백업 / 불러오기에서 백업 파일(.json)을 내려받아, 다른 기기에서 ‘백업 파일 불러오기’로 엽니다.
      • 브라우저 기록·사이트 데이터를 지우거나 시크릿(사생활 보호) 창을 쓰면 일지가 사라집니다. 일주일에 한 번쯤 백업해 두세요.
      • 학교·도서관 같은 공용 컴퓨터에서는 제출 후 일지를 삭제하세요.

      6. 질문하기 (챗봇)

      일지를 쓰다 막힐 때 질문하기 탭에서 Claude(AI)에게 물어볼 수 있어요. 작성 원칙을 바탕으로 답하고, 일지를 대신 써 주지는 않습니다. 쓴 글을 붙여 넣으면 원칙에 비추어 고칠 점을 짚어 줍니다.

      1. 설정 탭에서 API 키를 입력하고 키 저장을 누릅니다. 키는 Claude Console(platform.claude.com)에서 만듭니다.
      2. 같은 화면의 ‘최신 모델 불러오기’를 누르면 내 키로 쓸 수 있는 최신 Claude 모델 목록이 나옵니다. 사용할 모델을 고르세요. 잘 모르겠다면 sonnet이 들어간 모델을 권합니다.
      3. 질문하기 탭에서 궁금한 점을 쓰고 보내기를 누릅니다. 아래 예시 질문을 눌러도 됩니다. 컴퓨터에서는 Enter로 보내고 Shift+Enter로 줄을 바꿉니다.
      • 키는 이 기기의 브라우저에만 저장되며 백업 파일에는 들어가지 않습니다. 공용 컴퓨터에서는 쓰고 나서 설정에서 키 삭제를 누르세요.
      • 질문 내용은 답변을 만들기 위해 Claude(Anthropic) 서버로 전송됩니다. 클라이언트 실명, 전화번호, 주소는 쓰지 마세요. 개인정보처럼 보이는 표현이 있으면 보내기 전에 알려 줍니다. 쓰고 있는 일지는 전송되지 않고, 대화는 화면을 닫으면 사라집니다.
      • AI 답변은 틀릴 수 있습니다. 학교·기관의 기준은 담당 교수님이나 슈퍼바이저께 확인하세요.

      7. 자주 묻는 질문

      일지를 다 썼는데 저장 버튼이 없어요.
      입력할 때마다 자동 저장됩니다. 화면 위쪽에 저장 상태가 표시됩니다.
      어제 쓴 일지가 안 보여요.
      다른 기기나 다른 브라우저에서 쓰지 않았는지 확인하세요. 일지는 쓴 기기의 브라우저에만 있습니다.
      점검에서 경고가 떴는데 제 글은 문제없는 것 같아요.
      자동 점검은 참고용이라 잘못 짚을 수 있습니다. 직접 읽어 보고 괜찮으면 체크하고 넘어가세요.
      AI가 일지를 대신 써 주나요?
      아니요. 대신 쓴 일지는 슈퍼비전의 의미가 사라지기 때문에, 이 앱은 틀과 점검만 제공합니다. 질문하기 챗봇도 일지를 대신 쓰지 않고 쓰는 방법만 안내하도록 되어 있습니다.
      질문하기에서 “API 키가 필요해요”라고 나와요.
      설정 탭에서 API 키를 저장해야 쓸 수 있습니다. 키는 기기마다 따로 입력해야 합니다.
      챗봇이 오류를 보여 줘요.
      메시지의 안내를 먼저 보세요. “키가 올바르지 않아요”는 설정에서 키를 다시 입력하고, “모델을 찾을 수 없어요”는 ‘최신 모델 불러오기’를 눌러 모델을 다시 고르면 대부분 해결됩니다.

      실습일지 질문하기

      실습일지를 어떻게 써야 할지 궁금한 점을 물어보세요. 일지를 대신 써 주지는 않고, 작성 원칙에 맞게 직접 쓸 수 있도록 도와줍니다.

      질문하려면 API 키가 필요해요. 설정에서 키를 입력해 주세요.

      AI 답변은 틀릴 수 있어요. 학교·기관의 기준은 담당 교수님이나 슈퍼바이저께 확인하세요. 입력한 질문은 Claude(Anthropic) 서버로 전송되니 클라이언트 실명·연락처 같은 개인정보는 쓰지 마세요. 대화는 이 화면을 닫으면 사라지고, 쓰고 있는 일지는 전송되지 않습니다.

      설정

      Claude API 키

      키는 Claude Console(platform.claude.com → API keys)에서 만들 수 있어요. 키는 이 브라우저에만 저장되고, 질문을 보낼 때 Anthropic 서버(api.anthropic.com)로만 전송됩니다. 일지 내용이나 백업 파일에는 포함되지 않아요.

      사용할 모델

      챗봇이 사용할 Claude 모델을 고릅니다. ‘최신 모델 불러오기’를 누르면 내 키로 쓸 수 있는 최신 모델 목록을 Anthropic에서 가져와 목록을 갱신해요.

      고르는 요령: 이름에 haiku가 들어간 모델은 보통 빠르고 저렴하고, sonnet은 품질과 비용의 균형이 좋고, opus는 가장 정교하지만 비용이 더 들어요. 학생 질문처럼 짧은 대화에는 sonnet이나 haiku로 충분해요.

      알아 두세요

      • 키 사용료는 키 주인의 Anthropic 계정에 청구돼요. 다른 사람과 공유하는 기기에서는 쓰고 나서 키 삭제를 눌러 주세요.
      • 이 앱은 서버가 없어서, 키는 입력한 기기의 브라우저에만 있어요. 학생마다 자기 기기에서 따로 입력해야 챗봇을 쓸 수 있어요.
      • 챗봇은 일지를 대신 쓰지 않도록 설정되어 있지만, AI라서 완벽하게 지켜지지는 않을 수 있어요.
